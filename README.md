# Todo Web App

This is a simple Todo web application built with React and TypeScript. It allows users to create, edit, and delete tasks, as well as mark them as completed.
The application is powered by a backend API that handles the data storage and retrieval, the backend was built with Node.js, Express and TypeScript, the data is stored in a Mongo database.

## Getting Started
This application uses a backend API to manage the tasks. You can find the backend code in https://github.com/DiEmmal/todo_express_api

To run the application, you need to have Node.js and npm installed on your machine. You can download them from https://nodejs.org/en/download/
After installing Node.js and npm, follow these steps to run the application:

1. Clone the repository to your local machine.
2. Navigate to the project directory in your terminal.
3. Install the dependencies by running the following command:
```bash
npm install
```
4. Start the development server by running the following command:
```bash
npm run dev
```
5. Open your web browser and go to http://localhost:5173 to see the application

## About the Project

This project is the frontend part of a Todo web application. It is built using React and TypeScript, and it communicates with a backend API to manage the tasks.

The goal of the project is to practice building a full-stack web application using modern web development technologies, being manteined and improved over time, and to learn how to work with APIs and manage state in a React application.
